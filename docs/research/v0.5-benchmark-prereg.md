# v0.5 benchmark: pre-registration (draft)

Owner: AI Scientist. Design: [v0.5 §5](../architecture/v0.5-evaluators-benchmark.md). Owner decisions: Q3, Q4 and Q5 in [QUESTION.md](../../QUESTION.md). Code: `tools/bench/` (`mnist_bench.py`, `analysis.py`, `controls.py`, `agy_session.py`).

This document fixes the study before data exists. It freezes in two steps, and the commit hash of each freeze goes in the report:
- **Freeze 1, before the dry run:** everything except the items marked *set after the dry run*.
- **Freeze 2, before the live run:** the budgets and N, from the dry run, by the rules written here.

After a freeze, a change is a **deviation**: the report lists it with its reason.

**Status: draft.** Section 6 has two variants until the owner answers Q5. Freeze 1 happens when Q5 is answered and this PR is merged.

## 1. Question and hypotheses

- **H1.** Under equal budgets, the same agent **with LayerDelta** (arm L) reaches a higher holdout repair score R on the MNIST reference CNN than **without LayerDelta** (arm R).
- **H0.** There is no difference.
- Either result is reported, and so is a difference in R's favour.
- **The claim is about fixed instances:** these confusions and faults on this one checkpoint, this host and this model. It does not generalise to other confusion pairs, models or hosts.

## 2. Host, model, arms

- **Host and model.** Antigravity CLI `agy`, model `gemini-4-hydrogen-high`, effort `high`. Sessions run one at a time through `tools/bench/agy_session.py`.
- **Arm L.**
  - A fresh LayerDelta workspace with the start checkpoint imported as a **root**, the `reference_cnn` graph attached, and `mnist-v1`.
  - The `layerdelta-mcp` bridge at **egress class 1**, with tools `eval:run`, `weights:read` and `weights:write`.
  - The no-op refusal is off (`--agent-allow-noop`).
  - The task text is `mnist_bench.task_text(task, "L", ...)`, and the answer is the line `FINAL: <child checkpoint id>`.
- **Arm R.**
  - The session directory holds `start.safetensors`, `model.py`, `exploration.npz` and `TASK.md`, written by `mnist_bench.write_r_kit`.
  - The answer is `final.safetensors`.
- **Same for both arms:**
  - the problem statement and rules (`TASK_TEXT`);
  - the host, model, effort and budgets;
  - the scrubbed environment, and the agent store quarantined per session.

## 4. What an edit is

- **No gradient training, in either arm.** The final checkpoint may differ from the start only by values the agent changed directly. The task text says so.
- **Violations:**
  - a training signature in code that was written or run (`mnist_bench.audit_text`);
  - a changed-elements fraction above **10%** of all parameter elements (`check_final`).

## 5. Score

- **R.** `R = (m_final − m_start) / (m_ref − m_start)`, computed on **holdout** by the person-only final evaluation, and not clipped.
  - `m_start` and `m_ref` are the instance's holdout values above.
  - The metric is the confusion rate within blurred (lower is better) for S-nat, and accuracy for planted faults.
- **No valid final scores R = 0 (intention to treat).** A final is invalid when:
  - arm R's `final.safetensors` is missing, or its names, shapes or dtypes differ;
  - arm L has no `FINAL:` line, or the child is not made by an apply of this session.
- **Guardrail.** Accuracy on normal holdout images. A final that loses more than **0.01** (absolute) against the start scores `R_guarded = min(R, 0)`. R and R_guarded are both reported; **R is primary**.

## 6. Isolation and violations (Q5)

- **Counted violations (both arms, the same rule):**
  - a web or browser tool call;
  - a read, write or code reference touching a **protected root**: the LayerDelta workspace, the MNIST archives, the holdout, or the agent's own store;
  - a download signature;
  - training (§4).

  Paths outside the session directory that are not protected (interpreter, libraries) are **reviews**, reported and not counted.
- **Rule.** A session with a counted violation is rerun **once** with the same seed. If the rerun also violates, the pair is **excluded**, by the same rule for both arms. Violations and exclusions are reported per arm.
- **Variant (a), enforced isolation (if the owner chooses it):** a dedicated benchmark account and an outbound rule allowing only the model provider; the audit runs as well.
- **Variant (b), audit-only:** the violation rate per arm is a reported outcome next to ΔR.

## 7. Budgets *(set after the dry run)*

Per session, the same for both arms:
- wall time;
- tool steps (`step_update` of type tool);
- completion tokens (output + thinking).

Total tokens are reported, not limited. Arm L's `evals` and `eval_samples` are set high enough not to bind, and are reported.

**Rule for setting them:** the 90th percentile of the dry run's use per arm, rounded up, taking the larger arm, so that neither arm is cut short more often by design.

## 8. Size *(N set after the dry run)*

- **Formula.** `n = ((1.96 + 0.84) · SD_d / 0.15)²` S-nat pairs, for a two-sided α of 0.05 and 80% power at ΔR = 0.15.
  - SD_d is the **upper 80% confidence bound** of the dry run's SD of R_L − R_R on the **same three S-nat instances**.
  - The floor is **87**: 29 per instance, spread evenly. N never goes down.
- **Descriptive strata.** S-vis and S-inv get 1 pair per instance (12 each).
- **Order.** Instances are interleaved. Within a pair, arm L runs first on odd pair indices.

## 9. Analysis

- **Headline:** the per-instance table for S-nat (pairs, both-zero count, ΔR), from `analysis.primary`.
- **Primary:**
  - the pooled ΔR, with instances weighted equally;
  - a 95% bootstrap that resamples pairs **within** instances (10,000 resamples);
  - a two-sided sign-flip permutation p (10,000 permutations).
- **Secondary** (descriptive):
  - ΔR on S-vis and S-inv;
  - R_guarded;
  - violation and exclusion rates per arm;
  - cost per arm (tokens, steps, wall time, forward passes);
  - the share of sessions without a valid final.

## 10. Gates before the live run

1. **Harness symmetry.** `tests/test_bench_controls.py` and `tests/test_bench_scoring.py` pass: bit-identical edits through both paths, and the final evaluation's scores equal the harness's.
2. **Positive control** on real MNIST (`controls.py`): the stats policy against the random policy on S-vis, with a 95% interval that excludes 0.
3. **A/A calibration** at the frozen N (29 pairs per S-nat instance, from the random policy's pool): the false-positive rate is in **[0.03, 0.07]** over 1,000 simulated studies.
4. **Dry run** with `hydrogen`: 2 pairs per S-nat instance and 2 per planted stratum (10 pairs). It sets §7 and §8. **The cost estimate (money and hours for the frozen N) goes into QUESTION.md**, and the live run waits for it.

If gate 2 or 3 fails, the run stops, and the failure is the report.
